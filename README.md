# The Robert A.F. Thurman Archive — Approach & Best Practices

A confidential one-page proposal on building a living digital archive of
Professor Robert A.F. Thurman's body of work.

This site is **password protected**. The page (`index.html`) contains only an
AES-GCM–encrypted payload; the document text is never present in plaintext in
the source. It decrypts in the browser only when the correct password is
entered.

## Deploy (GitHub Pages)
1. Push this repo to GitHub.
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch:
   `main` / root → **Save**.
3. The site publishes at `https://<username>.github.io/<repo>/`.
